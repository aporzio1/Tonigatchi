# Tonigatchi

A Sopranos-inspired virtual pet game built with React and Vite. Keep Tony fed, calm, respected, and healthy.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## GitHub Pages

This project is configured for the `Tonigatchi` repository at `https://aporzio1.github.io/Tonigatchi/`. Build the project and deploy the generated `dist` directory to the `gh-pages` branch.
